# City of Pinehaven Parks & Recreation

Fictional municipal website. Static HTML, CSS, and a little JavaScript. No build step, no npm.

Open `index.html` in a browser, or serve the folder with any static file server.

| File | Page |
| --- | --- |
| `index.html` | Home |
| `parks.html` | Parks (filter by tag; the loop to practice) |
| `programs.html` | Programs |
| `hours.html` | Hours & fees |
| `contact.html` | Contact form |
| `css/styles.css` | All styles |
| `js/main.js` | Menu, park filter loop, contact check |

City details (phone, email, address) are written into each HTML page. Change them in every file, or the header and footer will not match.

This is a career-portfolio project, not a live city service. Pinehaven, Alabama is fictional.
